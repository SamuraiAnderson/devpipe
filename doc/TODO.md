# RedPyMake 项目 TODO

## 背景：async 异步语义与 DAG 编排的关系

- **DAG 是"逻辑模型"（What to do）**：定义任务间的依赖关系，描绘执行蓝图。
- **async 是"执行模型"（How to do）**：只有引入 async/await，DAG 才能实现并发执行——对无依赖的任务（如同时向设备 A、B 推送文件）在同一事件循环中并行，极大缩短整体构建和测试时间。
- 将核心控制器底层通信改造为 async 语义，是完整实现 DAG 编排的必经之路。
